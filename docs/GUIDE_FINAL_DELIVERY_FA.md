# گزارش تحویل بازبینی نهایی راهبر و فرم ارزیابی

تاریخ: ۲۰۲۶/۰۹/۱۹. مبنای همین Repository: 095f1ec780433503f10b6e27bca68c8c673e5d1f.
این گزارش جایگزین گزارش‌های تاریخی برای وضعیت فعلی است. مشخصات مکمل فرم و جدول امتیازهای پاسخ ارسالی کاربر، مرجع نهایی پیاده‌سازی مدل 1.0 است.

## ساخته و اجرا شده

- داشبورد فارسی RTL با هویت بنفش/نیلوفر، چهار خلاصه واقعی و چهار حوزه اصلی؛ افراد سازمانی با افزودن/تغییر/پایان مسئولیت و تاریخچه.
- فهرست گروه‌ها، مدیریت ساختار در مسیر جدا، پرونده مشترک خانواده، انتخاب پایدار و لغو صریح، انتقال با تاریخچه مبدأ/مقصد.
- آرشیو نهایی مصوبات با جست‌وجو و فیلتر، جزئیات/پیوست/تاریخچه فقط‌خواندنی.
- پنج فرم داده‌محور مشترک: معیشت، سلامت، مسکن، آسیب‌پذیری و آموزش؛ سرگروه مسئول پیش‌نویس را تکمیل می‌کند، راهبر همان ساختار ثبت‌شده را فقط می‌بیند.
- جدول پاسخ و وزن مصوب در مدل نسخه‌دار سمت سرور؛ صفر واقعی، آموزش نامشمول، داده نامشخص، نرمال‌سازی، سطح A/B/C/D و استقلال فوریت/بحران. عدد امتیاز دستی پذیرفته نمی‌شود.
- Snapshot تغییرناپذیر پاسخ‌ها، اعضا، شواهد، مدل و نتیجه؛ نسخه بعدی مستقل، تاریخچه ایجاد/ویرایش/ثبت/محاسبه. تغییر اطلاعات جاری اعضا، تاریخچه را تغییر نمی‌دهد.
- بارگذاری شاهد برای سرگروه مسئول، با سقف ۲۵۶ کیلوبایت و قالب‌های PDF/PNG/JPEG/Text؛ ثبت سند و ارجاع آن در Snapshot.
- هشدار مستقل از یادآوری و اعلان؛ جلوگیری از تکرار، مالک سرگروه، گردش مرحله‌ای و ثبت اقدام/نتیجه؛ راهبر ناظر است. حذف عامل محرک هشدار را خودکار حل نمی‌کند. اعلان درون‌سامانه‌ای بر زیرساخت موجود حفظ شده است.
- گزارش‌های مدیریتی خانواده/نیاز، حمایت موردی و مستمر، گروه/ظرفیت و طرح نهایی؛ خروجی واقعی XLSX و پیش‌نمایش چاپ. گزارش‌ها از داده موجود می‌خوانند، گردش اجرایی جدید حمایت/توزیع ساخته نشده است.

## فایل‌ها و پایگاه داده

Backend جدید: `apps/backend/src/oversight/` شامل scoring.ts، form-schema.ts، assessment.service.ts، oversight.service.ts و oversight.module.ts.
Frontend جدید: AssessmentForm.tsx، FinalGuide.tsx، FinalPeople.tsx و vocabulary.ts در `apps/frontend/src/pages/`؛ مسیرها و صفحات مشترک موجود اصلاح شده‌اند.
Seed تکمیلی: `apps/backend/scripts/seed-guide-final.ts`، فراخوانی‌شده از seed-guide-dev.ts؛ نام‌های فارسی، سه گروه و نه خانواده نمونه و نه ارزیابی نسخه‌دار. داده‌های شناخته‌شده Development هدف قرار می‌گیرند؛ Seed رمز موجود و تصمیم نهایی را بازنشانی نمی‌کند.

- `0007_guide_final_foundation.sql`: ساختار مدل/Snapshot، هشدار و یادآوری مستقل، آرشیو مصوبات و تاریخچه منبع.
- `0008_assessment_forms_v1.sql`: مدل و فرم مصوب 1.0، پیش‌نویس نسخه‌دار، محافظ تغییرناپذیری مدل/سند.

شش Migration قبلی حفظ شده‌اند. هر هشت Migration روی PostgreSQL واقعی از صفر اجرا شدند. ارتقای پایگاه محلی موجود نیز انجام شد؛ مقایسه هش محتوای سه درخواست دسترسی و سه تصمیم قبل/بعد یکسان بود. Seed تکمیلی روی همان پایگاه اجرا شد.

## APIهای جدید

مسیرها نسبت به پیشوند API تنظیم‌شده پروژه‌اند. کنترل Session/Role/Scope سمت سرور و CSRF برای نوشتن اعمال می‌شود.

- GET `/oversight/dashboard`, `/oversight/groups`, `/oversight/council`, `/oversight/council/:id`, `/oversight/reports/:section`, `/oversight/models`
- POST `/oversight/reports/export` برای preview و xlsx
- GET `/shared/groups/:id`, `/shared/families/:id`, `/shared/families/:id/assessments`, `/shared/alerts`
- POST `/shared/families/:id/draft`, `/shared/families/:id/assessments`, `/shared/families/:id/evidence`
- POST `/shared/alerts/:id/progress` برای مالک مجاز؛ `/shared/models/:id/transition` برای مدیر فنی مجاز

## آزمون واقعی

ساخت TypeScript بک‌اند، ابزار Migration/Seed، TypeScript فرانت‌اند و Vite موفق بود. تست‌ها با Chrome واقعی و PostgreSQL واقعی در پایگاه‌های جدا اجرا شدند؛ پایگاه آزمون در پایان حذف می‌شود.

- ورود: ۳۱ PASS
- درخواست‌های دسترسی: ۲۲ PASS
- راهبر/ارزیابی: ۱۸ سناریوی چندمرحله‌ای PASS
- جمع: ۷۱ PASS، صفر FAIL

این شمارش سناریوهاست، نه ادعای پوشش تمام حالت‌های ممکن. فایل `FINAL_TEST_RESULTS.json` نام و نتیجه هر سناریو را دارد. تست راهبر شامل جدول امتیاز دقیق، N/A، صفر، Unknown، استقلال Critical، منع امتیاز دستی، منع ویرایش راهبر/همیار، Snapshot تاریخی، سند تغییرناپذیر، انتقال وضعیت مدل، چرخه هشدار، انتقال خانواده، گزارش، ثبت کامل فرم در مرورگر و نمای موبایل است. آزمون‌های قدیمی ورود و Access Requests حفظ شده‌اند.

## عمداً حذف یا غیرفعال شده

منوی درخواست دسترسی از داشبورد حذف شده ولی مسیر مستقیم و آزمون‌های آن حفظ‌اند. گردش مجوز و مداخله راهبر در مصوبات بازنشسته شده‌اند. راهبر دکمه حل هشدار یا ویرایش ارزیابی ندارد. PDF در گزارش جدید غیرفعال است. رتبه‌بندی عملکرد گروه‌ها و نمایش داده خام جزو گزارش مدیریتی نیست.

## Deferred و محدودیت‌های واقعی

- داشبورد کامل سرگروه/مدیر فنی و UI مدیریت مدل امتیازدهی؛ این تحویل فقط فرم مشترک و کنترل دسترسی لازم را دارد.
- آستانه عددی ظرفیت گروه و حد «تغییر معنادار» امتیاز هنوز مصوب نیست: ظرفیت توصیفی و تغییر دقیق امتیاز نمایش داده می‌شود؛ قاعده کسب‌وکار جدید اختراع نشده است.
- جلوگیری از Double Counting متکی به ساختار جمع‌بندی و پاسخ‌های ثبت‌شده است؛ سامانه از متن آزاد تشخیص پزشکی خودکار نمی‌دهد.
- تولید PDF تأییدشده، چاپگر فیزیکی، آزمون بار/استقرار Production و سخت‌سازی نهایی انجام نشده‌اند.
- Workflow کامل عملیات حمایت، مقرری و توزیع، Offline، Push و 2FA در این تحویل ساخته نشده‌اند؛ نمایش گزارش از داده موجود به معنی تکمیل این عملیات نیست.
- پیوست بزرگ‌تر از سقف فعلی و چرخه کامل مدیریت فایل Deferred است. ارسال اعلان خارجی جدید ساخته نشده است.
- مسیر نصب از صفر مستند است؛ روی Windows دوم مستقل اجرا نشده است. ZIP شامل Dependency و ابزار نصب‌شده نیست و نصب وابستگی‌ها اینترنت می‌خواهد.

## تحویل و بازیابی

ZIP شامل Source، Git، lockfile، هشت Migration، Seed، تست، README و `.env.example` است؛ رمز واقعی، .env، node_modules، Database و Build محلی داخل آن نیست. برای اجرای تازه همین ZIP و نصب Node/pnpm/PostgreSQL کافی است؛ رمز توسعه را Seed تعاملی محلی می‌گیرد. برای حفظ داده واقعی جاری، Backup امن PostgreSQL جداگانه لازم است. این ZIP نسخه پشتیبان داده نیست.
Commit این مرحله محلی است؛ Push به GitHub در این مرحله انجام نشده است. اسناد تست‌های قبلی صرفاً تاریخچه‌اند.
