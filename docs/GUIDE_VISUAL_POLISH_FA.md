## تغییرات

- کارت‌های خلاصه با رنگ‌های لطیف متمایز، آیکون‌های هماهنگ، سلسله‌مراتب عنوان و مقدار، سایه و حاشیه ظریف.
- نوار توجه فشرده و کارت‌های چهار حوزه با خط بنفش، فاصله‌گذاری و دکمه‌های روشن‌تر.
- نمودارهای سفارشی با نوار باریک، انتهای گرد، پنج رنگ ملایم و مقدار قابل‌خواندن برای ابزارهای کمکی. صورت و مخرج محاسبه نوارها عیناً حفظ شده‌اند.
- اصلاح ظاهر فیلترها، جدول، نشان‌های سطح/فوریت/وضعیت و صفحه‌بندی؛ حالت hover، focus و disabled.
- سبک‌ها فقط در دو محدوده opt-in اعمال می‌شوند؛ سایر صفحات همان سبک پیشین را دارند.

## فایل‌ها

- `apps/frontend/src/pages/GuideVisualPolish.css`: سبک‌های محدود به همین دو صفحه.
- `apps/frontend/src/pages/GuideSlice.tsx`: اتصال دو محدوده نمایشی، رسم نوار نمودار و پوشش نمایشی نشان‌ها. مسیرها، متن‌ها، APIها، داده‌ها، شمارش‌ها، فیلترها و مرتب‌سازی حفظ شده‌اند.
- `tests/family-read-slice.mjs`: انتظار برای پایان رندر فیلتر پیش از مقایسه تعداد ردیف‌ها؛ همان معیار و تعداد مورد انتظار قبلی حفظ شده است.
- `docs/GUIDE_VISUAL_POLISH_FA.md`: این گزارش.
- `docs/GUIDE_VISUAL_POLISH_RESULTS.json`: خروجی کامل نتایج آزمون نهایی.

هیچ Backend، Migration، Seed، Schema، Permission یا Workflow تغییر نکرده است.

در اجرای اول، آزمون تعداد ردیف‌ها بلافاصله بعد از انتخاب فیلتر، قبل از رندر React بررسی می‌شد و شکست خورد. همان آزمون با انتظار شرطی برای URL و تعداد واقعی ردیف‌ها اصلاح شد؛ هیچ assertion حذف یا ضعیف نشد. سپس کل مجموعه دوباره اجرا شد و ۸۲ مورد موفق بودند.
Build همچنان هشدار غیرمسدودکننده قبلی درباره bundle بالای ۵۰۰ کیلوبایت دارد.
آزمون‌های پایگاه‌داده از دیتابیس‌های جداگانه آزمایشی استفاده کردند؛ داده فعلی توسعه برای این اصلاح ظاهری بازنویسی نشد.
