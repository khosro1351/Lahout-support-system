# نقشه اثر یکپارچگی ارزیابی خانواده

مبنا: Master Specification و تصمیم مصوب یک موتور عملیاتی، پرونده خانواده نقطه ورود، تأیید مدیر شرط نتیجه معتبر.

| بخش | اصلاح محدود | حفاظت |
|---|---|---|
| پرونده و ناوبری حوزه‌ها | اتصال مستقیم به فرم‌های جامع موجود | اطلاعات پایه جاری مستقل از Snapshot |
| سرویس وضعیت مشترک | Approved، Draft، Pending و مدل جاری مجزا؛ وضعیت حوزه، مشمولیت، امتیاز و اقدام بعدی | FINAL به معنی Approved نیست |
| فهرست و داشبورد و گزارش | مصرف قرارداد مشترک و نمای SQL تأییدشده | امتیاز Draft/Submitted وارد گزارش نهایی نمی‌شود |
| مسیرهای قدیمی | هدایت مسیر عادی به جامع؛ تاریخچه خواندنی و منع ثبت قدیمی | داده، پاسخ و Snapshot قبلی باقی می‌ماند |
| تغییر نسخه مدل | حفظ مرجع قبلی و تأیید بازنگری هر پنج حوزه در نسخه جاری | بدون ساخت خودکار Draft برای خانواده بدون ارزیابی باز |
| آزمون | PostgreSQL ایزوله، دسترسی، Audit، مرورگر و مقایسه بین مصرف‌کنندگان | پایگاه واقعی Reset/Seed نمی‌شود |

سه فایل راه‌اندازی قبلی خارج از این مأموریت و Commit باقی می‌مانند. main و remote تغییر نمی‌کنند.
