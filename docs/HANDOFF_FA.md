# تحویل برای ادامه توسعه

- مبنا همان Repository قبلی است؛ قواعد اجرایی این مرحله در SUPREME_GUIDE_SPEC_FA.md و تصمیم‌های پیاده‌سازی در GUIDE_WORKSPACE.md ثبت شده‌اند.
- ابتدا README و GUIDE_WORKSPACE_TESTS_FA.md را بخوانید. برای نصب تازه پنج Migration و سه Seed توسعه وجود دارد. رمزهای محلی را از فایل ZIP انتظار نداشته باشید.
- پنل راهبر روی `/guide` است. مخاطبان فقط `/workspace` را دارند؛ این مسیر جایگزین پنل اجرایی کامل نقش‌های آینده نیست.
- Access Requests همچنان تصمیم سازمانی غیرقابل ویرایش است. آن را با انتصاب مستقیم که فوراً Role/Scope را اعمال می‌کند ادغام نکنید.
- PostgreSQL تاریخچه/Audit را حفظ می‌کند؛ برای تغییر سرگروه یا نقش از Business Action موجود استفاده کنید تا Scope و اعلان با هم ثبت شوند.
- مخاطبان تصمیم در زمان ارسال به Accountها تبدیل و ذخیره می‌شوند. تغییر نقش آینده، مخاطبان یک تصمیم قبلی را بی‌صدا بازنویسی نمی‌کند.
- پیش از هر Slice بعدی، سه مجموعه `pnpm test` را اجرا کنید. تغییر انتظارهای تست باید مستند و ناشی از تغییر تأییدشده نیازمندی باشد.
- نقاط اتصال بعدی: ورود مصوبات از فضای شورا، نگهداری بانک افراد از فرآیند مبدأ، تأمین حساب توسط مسیر فنی، انتقال خانواده از گروه منحل‌شده، داده‌های حمایت/ارزیابی برای گزارش‌ها و Export صفحه‌آرایی‌شده.
- توسعه این تحویل در Git محلی ثبت می‌شود؛ همگام‌شدن آن با GitHub بدون نتیجه Push موفق ادعا نمی‌شود.
