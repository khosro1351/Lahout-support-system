# Design Freeze — Pilot logic

The project intentionally follows a **build-first, design-on-demand** rule from this point forward.

## Pilot Core
- Secure login and role-aware access
- Organization groups and scopes
- Minimal family registration and file view
- Family core
- Assessment and scoring
- Need / request / investigation
- Council / vote / resolution
- Support / impact review
- Follow-up / taskbox
- Essential documents, audit, reports and backup

## V1 after pilot
- Full stipend lifecycle
- Distribution plans and ranking
- Full crisis workflow
- Advanced leadership hold/reconsideration
- Push notifications
- Advanced offline sync/conflict handling
- Advanced reporting/settings/document versioning

## Later
- Kurdish UI
- Native apps
- Custom dashboards/report builder
- External integrations/advanced BI

Business rules already approved remain the design reference. Features are not implemented early merely because they have been designed.
