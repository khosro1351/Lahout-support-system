Typecheck و Build هر دو برنامه PASS هستند. تست‌ها با PostgreSQL واقعی و Chrome/Playwright در Windows اجرا شدند. هر مجموعه Database موقت مستقل می‌سازد و پاک می‌کند. ۳۱ تست ورود، ۲۲ تست Access Requests و ۲۵ تست جدید مجموعاً ۷۸ تست‌اند. فایل GUIDE_TEST_RESULTS.json نام تک‌تک بررسی‌ها و زمان اجرا را دارد.

در طول توسعه، خاموش بودن PostgreSQL، اتصال برچسب یک فیلد و انتخاب مبهم متن در تست مرورگر شناسایی و رفع شدند. این گزارش نتیجه اجرای نهایی است، نه ادعای اینکه هیچ اجرای ناموفقی در روند توسعه وجود نداشت.

دو انتظار مربوط به مرحله قبلی به‌صورت آگاهانه به‌روز شدند: داشبورد اکنون هفت حوزه فعال دارد؛ و حساب دارای نقش غیرراهبر می‌تواند فقط وارد فضای محدود مخاطب شود. ورود حساب بدون نقش/غیرفعال همچنان رد می‌شود و تمام Endpointهای راهبر برای غیرراهبر ممنوع‌اند. fixture چند راهبر هم‌زمان حذف شد تا با یکتایی راهبر سازگار باشد. منطق تأیید/رد Access Requests تغییر نکرد.

## مسیرهای واقعی مرورگر

- ورود Aseman، داشبورد فارسی RTL با هویت بنفش و نیلوفر آبی.
- افراد → پرونده فرد → ثبت مسئولیت → Refresh و مشاهده مسئولیت.
- گروه → انتخاب سرگروه جدید → تأیید و مشاهده نتیجه.
- تصمیم راهبر → ایجاد مأموریت → ورود حساب مخاطب → مشاهده → ثبت نتیجه → Refresh راهبر و مشاهده نتیجه ثبت‌شده.
- مصوبه شورا → بازگرداندن برای بازنگری → تأیید → لغو → Refresh و تاریخچه.
- گزارش‌ها → پیش‌نمایش گزارش حامی؛ بررسی عرض موبایل صفحات اصلی و نبود خطای JavaScript.
- تمامی مسیرهای قبلی درخواست دسترسی، رد بدون دلیل، تصمیم هم‌زمان، قفل تصمیم و Audit مجدداً پاس شدند.

## یکپارچگی پایگاه داده موجود

Migration پنجم روی Database موجود نیز اجرا شد. هش محتوای تمام درخواست‌های دسترسی و تصمیم‌های آن‌ها پیش و پس از ارتقا یکسان بود: ۳ درخواست و ۳ تصمیم محفوظ ماندند. Seed جدید روی این Database موجود اجرا نشد؛ برای تست‌ها از Databaseهای جداگانه استفاده شد.

برنامه محلی روی پورت‌های ۳۰۰۰ و ۵۱۷۳ راه‌اندازی شد؛ صفحه ورود پاسخ ۲۰۰ و Endpoint هویت بدون نشست پاسخ صحیح ۴۰۱ داد. رمز فعلی Aseman تغییر نکرد.

## حدود تحویل

این نسخه قابل اجرا و قابل تست است؛ ادعای تکمیل همه قابلیت‌های آینده سامانه ندارد. خروجی PDF/Excel صفحه‌آرایی‌شده، داده و فیلترهای حمایت/ارزیابی آینده، گردش‌کار مبدأ شورا و بانک افراد، انتقال اجرایی خانواده‌ها و پنل مدیریتی نقش‌های دیگر Deferred هستند. گزارش حامی فعلاً پیش‌نمایش و خروجی JSON با حذف پیش‌فرض اطلاعات هویتی دارد. Notification داخلی واقعی است؛ Push/SMS/Email ساخته نشده است.

اطلاعات نصب ابزارها و وابستگی‌ها در README آمده است. ZIP شامل Source و Git است و شامل node_modules، Build، .env محلی، Password واقعی یا داده Database نیست. اجرای Windows دوم در این مرحله انجام نشد؛ تست روی Windows موجود با Databaseهای تازه انجام شد.
